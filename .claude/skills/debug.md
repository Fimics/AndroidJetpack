# /debug - 调试分析

分析崩溃日志、ANR、性能问题，定位根因并提供修复方案。

## 步骤

1. 用户提供错误信息（logcat 日志、堆栈跟踪、ANR trace、或问题描述）
2. 分析错误类型：
   - **崩溃**：解析堆栈，定位到源码行号，分析空指针/类型转换/数组越界等原因
   - **ANR**：分析主线程阻塞原因（IO、死锁、长计算）
   - **内存泄漏**：检查 Activity/Fragment/View 引用链
   - **编译错误**：分析 Gradle 构建日志
   - **运行时异常**：SecurityException（权限）、IllegalStateException（生命周期）等
3. 在项目代码中定位相关源码
4. 提供修复方案和代码修改
5. 如果是常见坑，说明根本原因和预防措施
