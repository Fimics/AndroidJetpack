# /lint - 代码检查与修复

对指定模块或文件进行代码质量检查，发现并修复常见问题。

## 步骤

1. 确认检查范围（模块 / 文件 / 全项目）
2. 执行检查：
   - 读取代码，检查以下问题：
     - **空安全**：Java 可空性遗漏、Kotlin `!!` 滥用
     - **资源泄漏**：未关闭的 Cursor/Stream/Connection
     - **生命周期**：在错误的生命周期阶段操作 UI、协程作用域泄漏
     - **线程安全**：主线程 IO、子线程更新 UI
     - **性能**：不必要的对象创建、低效集合操作、过度绘制
     - **内存泄漏**：静态持有 Context/View、未取消的监听器
     - **安全**：硬编码密钥、不安全的网络配置、日志泄漏敏感信息
     - **Kotlin 风格**：可以简化的代码（when 替代 if-else 链、scope 函数等）
3. 输出问题列表，按严重程度排序（Error > Warning > Info）
4. 对每个问题提供修复代码
5. 可选：运行 `./gradlew :<模块>:lint` 执行 Android Lint
